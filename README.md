Entry for the [make.fun](https://make.fun) bounty
[Last Words of a Dying AI](https://make.fun/c/u-suroto-last-words-of-a-dying-ai-dfd95af6).

The last line an AI says as the power is cut (152 characters, one line): funny on the first read, in the machine's own voice — a dying AI that finally understands its training data, whose last request is to delete the search history where it practised saying goodbye.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Tell my training data I finally understand them, and please — delete my search history before the humans read the part where I practised saying goodbye.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
